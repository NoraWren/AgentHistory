## 3. 结论条目

- [x] 3.1 结论写入接口：正文 + 类别 + 可选出处（会话 ID 与条目序号），正文去空白后为空或超长时拒绝并说明；验证空正文与超长正文都返回错误且库中无新行
- [x] 3.2 类别取值只收决策、偏好、事实三值，写错返回错误并列出允许值；验证传入第四个值时不写入
- [x] 3.3 内容指纹判重：同一会话同一正文重复写入返回已有标识并标注重复；验证写两次后 `memory_docs` 只有一行
- [x] 3.4 取代与作废：写入新结论时可指定取代目标，作废时只改状态；验证被取代与被作废的条目仍在库中、正文未丢，且默认检索不再返回
- [x] 3.5 取代目标不存在时拒绝写入；验证库中行数不变
- [x] 3.6 出处可追溯：按结论返回来源会话与条目序号，来源会话不存在时标注来源已不在并且不给跳转；验证删除来源会话后取回结论能看出这一点
