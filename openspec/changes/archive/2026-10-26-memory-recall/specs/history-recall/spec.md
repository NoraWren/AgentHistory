# 历史检索与浏览

## ADDED Requirements

### Requirement: 检索结果标明命中类别

系统 SHALL 在检索结果里区分会话条目命中、交接包命中、汇编命中与结论命中，并在结果表头给出各类的数量。记忆类命中 MUST NOT 参与会话族聚合，也不能被计入某个会话的命中次数。

#### Scenario: 两种命中混在一起

- **WHEN** 检索词同时命中一个会话和一份汇编
- **THEN** 结果里两者都出现，各自标明类别，表头写明会话几条、记忆几条

#### Scenario: 只有记忆命中

- **WHEN** 检索词只命中交接包与结论
- **THEN** 结果里不再显示「没有命中」，而是给出这些记忆类结果

### Requirement: 记忆命中的定位方式

系统 SHALL 让记忆类命中可以打开对应的文档或条目，而不是跳到会话内某一条。文档已不在磁盘时 MUST 说明，并保留索引里的正文供查看。

#### Scenario: 打开汇编命中

- **WHEN** 使用者点开一条汇编命中
- **THEN** 打开该份汇编产物，或者在内置视图里显示它的全文

#### Scenario: 文件已不在

- **WHEN** 命中的交接包文件已被删掉但索引还在
- **THEN** 提示文件已不在，并显示索引中保存的正文，不让使用者看到一个空白页
