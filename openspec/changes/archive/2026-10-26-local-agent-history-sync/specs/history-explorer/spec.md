# 历史浏览界面

## Purpose

提供一个 macOS 原生界面，用来浏览、搜索和同步本机各客户端的会话历史。

## ADDED Requirements

### Requirement: 三栏浏览

界面 MUST 以来源与项目筛选、会话列表、会话时间线三栏组织，并能记住上次选择。

#### Scenario: 打开应用
- **WHEN** 用户启动应用
- **THEN** 左侧显示来源与项目，中间显示按最近活动排序的会话，右侧提示选择会话

#### Scenario: 选中会话
- **WHEN** 用户点击一条会话
- **THEN** 右侧按顺序显示用户消息、助手回复、推理与工具调用，推理和工具调用默认折叠

### Requirement: 同步向导

界面 MUST 用一次向导完成来源选择、目标选择、预览、执行和结果展示。

#### Scenario: 完成一次同步
- **WHEN** 用户依次选择来源、目标并确认预览
- **THEN** 界面显示进度条和当前阶段，结束后显示结果摘要并可在目标客户端中核对

#### Scenario: 预览后放弃
- **WHEN** 用户在预览页取消
- **THEN** 不产生任何写入，返回浏览状态

### Requirement: 全局搜索

界面 MUST 提供全局快捷键唤起的搜索入口，结果可定位到具体会话和具体条目。

#### Scenario: 快捷键搜索
- **WHEN** 用户按下全局快捷键并输入关键词
- **THEN** 显示跨客户端的命中列表，点击后打开对应会话并定位到该条目

### Requirement: 大会话可用

界面 MUST 对条目数量很大的会话分页加载，不因单个会话过大而卡顿。

#### Scenario: 打开超大会话
- **WHEN** 用户打开一个包含数千条条目的会话
- **THEN** 首屏在合理时间内显示，滚动时按需加载后续条目

### Requirement: 来源状态可见

界面 MUST 展示每个来源的可用状态、上次同步时间和本次增量数量。

#### Scenario: 来源不可用
- **WHEN** 某个来源的数据目录缺失或结构不兼容
- **THEN** 该来源在状态区显示为不可用，并给出可读的原因

### Requirement: 原生系统集成

界面 MUST 以 macOS 原生应用形式运行，最低支持 macOS 14.0，并提供菜单栏入口。

#### Scenario: 从菜单栏查看
- **WHEN** 用户点击菜单栏图标
- **THEN** 显示今日新增会话数、最近会话和同步状态，可直接打开主窗口
