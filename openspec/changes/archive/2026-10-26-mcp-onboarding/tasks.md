# 任务：MCP 接入面板

## 1. 客户端注册表

- [x] 1.1 定义客户端描述结构与接入方式分类（配置式、命令式、插件式），覆盖 Codex、Claude Code、WorkBuddy、OpenCode、Kimi Code、DeepSeek Harness 六项，每项写明根目录、登记文件、格式与官方命令。验证：单元测试断言六项齐全且路径不重复。

## 2. 握手检查

- [x] 2.1 实现握手：拉起一次 `AgentHistory mcp` 子进程，发送 `initialize`，再发 `tools/list`，解析返回的工具名集合，带 5 秒超时并确保超时后回收子进程。验证：对本机当前可执行文件调用，断言取回六个工具名。
- [x] 2.2 实现失败分类：可执行文件不存在、进程启动失败、握手超时、工具清单为空，各自带独立原因文案。验证：分别用不存在的路径、非可执行文件、立即退出的假脚本断言对应原因。
- [x] 2.3 组合出单客户端状态判定：未安装、未配置、已配置但连接不通过（含原因）、已接入（含工具数）。验证：四种状态各有临时环境用例，且「配置存在但路径失效」不得判成已接入。
